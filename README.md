# Playwright Automation Portfolio

A Playwright and TypeScript test automation portfolio demonstrating modern web application testing.

## Tech Stack
- Playwright Test
- TypeScript

## What This Portfolio Demonstrates
- Web-first assertions for reliable UI validation
- Form workflow validation and ARIA-live status checks
- Dynamic list interaction testing for client-side updates
- Cross-browser ready configuration (Chromium, Firefox, WebKit)

## Getting Started
```bash
npm install
npx playwright install
npm test
```

## Targeted Run (Chromium)
```bash
npm run test:chromium
```
